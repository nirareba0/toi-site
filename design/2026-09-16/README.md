## 開く

`index.html` をブラウザで開ける。ローカル配信する場合はこのディレクトリで:

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

http://127.0.0.1:8767/ を開く。ビルド・依存パッケージ・外部フォントは不要。

## 試せること

- ホーム、テーマ絞り込み、3つの問いと返事の例。
- 問い入力、公開同意、確認、書き直し、完了例。
- 返事の状態3種類（確認待ち・返事あり・公開見送り）の見本。
- 大人の返信入力・確認・完了例、ブラウザの戻る操作。

すべて架空の例文。入力は画面内メモリだけで扱い、リロードで破棄する。保存・送信・認証・公開・通知は実装していない。本番の返事確認用の秘密控えリンクと、Supabase接続は別工程。
